# Sistema de Doações

Projeto desenvolvido em Python para auxiliar no controle
de doações recebidas por projetos e organizações sociais.

## Funcionalidades

- Cadastro de doações
- Listagem de doações
- Identificação do doador
- Registro do tipo de doação
- Registro da quantidade

## Tecnologias

- Python
- Git
- GitHub

## Como executar

Execute o arquivo:

```bash
python main.py
